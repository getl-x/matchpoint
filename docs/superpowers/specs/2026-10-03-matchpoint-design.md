# 赛点初版设计

日期：2026-10-03

用户目标：先获得一个可以直接看外观并操作的网页初版，汇总 CS2、无畏契约、英雄联盟、Apex 的比赛进程。赛程是独立页面，可以下拉选择游戏和赛事。晋级队伍自动填入后续对阵。兼容手机，加入 iOS PWA 基础能力，暂不制作安卓客户端。

当前未收到图一、图二，先采用浅色背景、紫色强调、侧边导航、日期条、直播卡片和赛程列表。实现免费本地预览，不调用收费 API。所有比赛明确标为演示数据，真实数据接入留待后续。

## 页面与行为

- `/schedule`：游戏与赛事选择、日期选择、比赛状态筛选、队伍搜索、直播卡、比赛详情和关注。
- `/bracket`：CS2、无畏契约、英雄联盟的八队单败晋级图；比赛可录入结果或模拟下一场，结果自动传播。改变上游胜者时清除无效下游赛果。Apex 使用二十队积分榜，完成六轮后前十队进入下一阶段。
- `/following`：本地关注的赛程，不受当前日期限制。
- 对阵与关注使用版本化 localStorage 存储，坏数据自动回到初始示例，不阻塞页面。
- 安装入口展示浏览器可用的安装操作或 iOS「分享 → 添加到主屏幕」说明。静态文件由 Service Worker 离线缓存。手机正式安装须通过 HTTPS 访问；localhost 仅用于桌面开发。

## 架构与约束

原生 ES Modules、HTML、CSS；Node 内置静态服务器，无需安装第三方运行依赖。比赛演示数据、晋级计算、持久化、页面渲染分别放在独立文件。游戏图形与图标为本地 SVG，安装图标为本地 PNG。原型不读取外部数据，不声称实时监控已上线。

验证重点：上游赛果变更、未确定参赛队伍的比赛、非法或平局比分、Apex 同分排序、跨游戏数据隔离、刷新后的关注和晋级状态、手机溢出、离线重新访问。
