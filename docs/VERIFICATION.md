## 2026-10-06 视觉精修（广播风）

改动只落在 `styles.css`，不改 DOM、类名或 `data-*` 契约，JS 逻辑零改动。

- 建立语义令牌层：`:root` 与 `html[data-theme="dark"]` 各持一套完整取值（表面 / 文字 / 强调 / 状态 / 阴影 / 圆角 / 字阶 / 组件面）。原先硬编码的 389 个颜色值收敛为 29 个仍具语义的颜色（状态绿、琥珀、红、teal、归档与提醒语义色），其余全部改走令牌。
- 删除 31 条 `html[data-theme="dark"]` 逐组件覆盖块：基础规则改走令牌后这些覆盖是冗余的，深色模式现在由令牌值直接驱动，不再需要按组件打补丁。
- 字体原先在正文信息上使用 6–10px（共 219 处）。改为 11 / 12 / 13 / 14px 字阶，正文下限 11px；实测深浅主题均无低于 11px 的可见文字。
- 对比度按 WCAG 实算并修正：`--text-muted` 由 3.09:1 提升到浅色 5.46:1 / 深色 4.76:1；手机端赛事名由 2.8:1 提升到 7.32:1。16 类文字角色 × 深浅两主题共 32 项实测全部达到 AA（最低 4.53:1）。
- 数字统一 `font-variant-numeric: tabular-nums`（比分、开赛时间、日期、排名、积分、进度），赛程表列对齐。
- 清除同选择器同属性被后续世代覆盖的 165 条死声明（同 `@media` 上下文内只有最后一次生效，删除是视觉无变化的），并修正 `:root` 被声明两次、旧色板会赢回级联的问题。
- 圆角由 20 种取值收敛为 5 档；阴影由 11 个偏紫模糊统一为 3 级冷色 elevation。
