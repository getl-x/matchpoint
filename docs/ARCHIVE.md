# 赛事存档与后续赛季

本机服务启动后会自动读取四款游戏的官方历史目录，以两项并发补全可读取的往届比赛。首轮下载不需要用户逐届点击。服务运行期间，每 6 小时重新发现已结束赛事；页面的「同步存档」按钮可以立即启动发现与失败重试。

查询入口是「赛事存档」。支持游戏、年份、赛事名搜索，以及全部、已存档、暂不可读筛选。打开一届赛事后，显示正式官方场次与保存的赛果；CS 保留官方 Swiss/淘汰关系图，Riot 展示独立对阵节点，APEX 保留官方积分表。可导出 JSON，包含原始官方快照、来源和图布局，手机仍可局部滑动。

数据在 `data/archive/`，并非只放在浏览器缓存里。重启服务仍保留存档；浏览器额外保留最近查看的部分赛事，便于离线读取。不要删除此目录，迁移机器时复制整个目录即可保留已保存的官方历史记录。服务没有把这个目录当作静态资源开放，只通过限定赛事身份的 API 查询。

官方没有公开、已删除或者暂时不可读的数据不会推测补齐。「部分数据已存档」表示已保存官方可读场次，但缺失部分赛果、参赛队或分页，页面同时显示原因。更早首届数据不在上述官方可读范围内，不能把目前存档称作首届至今全集。

后续年份依赖官方持续公布的数据，而非固定赛事名单：CS 每次读取当前官网目录；Riot 每次读取当前公开赛程并匹配中国官方中文目录；ALGS 每次读取主赛季结构。已通过 2027、2028 年新 ID、新日期、新名称及新主赛季的测试。官网数据格式改变或停止公开时会显示来源错误并保留旧快照，需要更新读取适配器，不会生成虚假赛果。

实际验证：重启前 356 项存档全部保留，重启后补读到 360 项。统计与重启证据见 `archive-verification.json`；浏览器验收见 `browser-verification.json`。运行 `npm test` 和 `npm run test:browser` 可重新验证。
